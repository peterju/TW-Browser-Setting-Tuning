# Chrome & Edge 瀏覽器政策調整工具 (Policy Tuning Tool)
這是一組專為 **Google Chrome** 與 **Microsoft Edge** 設計的自動化調整腳本 (.cmd)，用於快速解決瀏覽器因安全政策限制而無法正常執行特定網站功能（如：憑證簽章、彈出式視窗）的問題。

## 🔍 解決核心問題
當您在使用政府機關、校園系統或 HiCOS 憑證元件時，常會遇到以下阻礙：
1. **私有網路存取限制 (Private Network Access)**：瀏覽器封鎖網頁呼叫本機端服務（如 `127.0.0.1` 或 `localhost` 的簽章元件），導致無法讀取卡片。2. **彈出式視窗封鎖**：重要登入頁面或下載視窗被瀏覽器自動攔截。

本工具透過修改系統政策 (Registry Policy)，將指定網域加入**白名單**以解除上述限制。

## ✨ 主要功能
- **權限自動偵測**：自動檢查並提示需以「系統管理員身分」執行。
- **雙重路徑寫入**：同時更新 `HKLM` (本機) 與 `HKCU` (使用者) 登錄檔，確保政策生效。
- **預設白名單設定**：
  - `[*.]ncut.edu.tw` (勤益科大)
  - `[*.]moica.nat.gov.tw` (內政部憑證管理中心)
  - `[*.]nat.gov.tw` (政府入口網)
- **自動套用設定**：執行後會自動重啟瀏覽器進程以即刻生效。

## 🛠️ 使用方法
1. 根據您使用的瀏覽器選擇檔案：
   - 使用 Chrome 請選：`Chrome_Policy_Fix.cmd`
   - 使用 Edge 請選：`Edge_Policy_Fix.cmd`
2. 在檔案上點擊 **右鍵**，選擇 **「以系統管理員身分執行」**。
3. 執行完畢後，腳本會自動重啟瀏覽器。
4. **驗證方式**：在網址列輸入 `chrome://policy` 或 `edge://policy`，檢查 `PopupsAllowedForUrls` 是否已出現上述網址。

## ⚙️ 如何自定義網域
若您需要新增其他網站（例如貴公司的網域），請用記事本開啟腳本，修改以下區塊：

```batch
:: 設定要加入白名單的網址
set "url1=[*.]yourdomain.com"
set "url2=[*.]another-site.org"
```
## ⚠️ 注意事項

* 強制關閉：執行時會強制結束瀏覽器所有視窗，請先儲存手邊的工作。
* 防毒軟體：部分防毒軟體可能會阻攔修改登錄檔的動作，若執行失敗請暫時關閉防毒。


## 📜 免責聲明
本工具僅供解決特定系統相容性問題使用。修改瀏覽器安全政策可能會降低部分安全性，請確認您信任白名單中的網域。
